# mindmeld

[![Release](https://img.shields.io/github/v/release/aschreifels/homebrew-mindmeld?include_prereleases)](https://github.com/aschreifels/homebrew-mindmeld/releases)
[![License: Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

Two minds, one accreting memory. Your knowledge base is a plain-markdown git
repo you own — readable with `cat` if every tool you use vanished tomorrow.
mindmeld ships the other half: rituals for opening and closing work, recall,
and structure, so the KB stays legible as it grows. Own the data, rent the
tools.

## Install

```bash
brew tap aschreifels/mindmeld
brew install mindmeld
mindmeld init
```
